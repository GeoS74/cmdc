# CMDC — CommonMark to HTML parser

Легковесный парсер Markdown, написанный на Си. 
Реализует спецификацию CommonMark v0.31.2, используя подход конечного автомата 
и стека тегов для обработки вложенных структур.

### Статус поддержки CommonMark (v0.31.2)
Подробный отчёт по всем протестированным примерам доступен в файле [`test_status.md`](test_status.md).

Краткий список поддерживаемых элементов:
- Tabs - частично
- Заголовки (Atx headings) - частично
- Параграфы (Paragraphs) - полностью, кроме жёстких переносов (пример 226)

### Сборка

```bash
make
```

Исполняемый файл cmdc появится в корневой папке.

### Использование

```bash
./cmdc < <md_file>
```
где,
- `<md_file>` - файл с markdown разметкой

### Тестирование

```bash
./test/test.sh
```
